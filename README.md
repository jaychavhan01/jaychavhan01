### 🌱 IoT Based Smart Irrigation System

> **Automated irrigation system based on real-time soil moisture levels**

An IoT-based smart irrigation system designed to automatically control a water pump according to soil moisture conditions.

**Key Features:**

* Automatically detects soil moisture levels
* Turns the water pump ON/OFF based on soil conditions
* Reduces unnecessary water consumption
* Designed for small-scale farmers and gardens
* Team project where I worked as the **Team Leader**

**Tech Stack:**

`Arduino / NodeMCU` `Embedded C` `Soil Moisture Sensor` `Relay Module`
